# CareNest 🏡💚
### Together in every moment of care.

CareNest is a family caregiving and reminder Android application designed to help families organize and manage the care of their loved ones. It brings medication reminders, daily tasks, appointments, emergency contacts, and important care information into one simple and user-friendly app.

The goal of CareNest is to make caregiving easier, more organized, and more connected.

---

## ✨ Features

- **🏠 Home Dashboard** — View today's medications, tasks, appointments, and important reminders at a glance.
- **💊 Medication Management** — Add medications, dosage instructions, schedules, and track whether medications have been taken.
- **⏰ Medication Reminders** — Receive notifications for scheduled medications.
- **✅ Daily Tasks** — Create, manage, and complete daily caregiving tasks.
- **📅 Appointments** — Keep track of medical appointments and important dates.
- **👨‍👩‍👧‍👦 Family & Care** — Manage care recipient information and family-related care details.
- **🚨 Emergency Contacts** — Store important contacts for quick access.
- **📝 Care Notes** — Keep important notes, allergies, and care instructions organized.
- **📱 Simple Interface** — A clean, accessible, and easy-to-use interface designed for everyday use.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Design:** Material 3
- **Architecture:** MVVM
- **Local Database:** Room
- **Notifications:** Android Notifications & AlarmManager
- **Background Tasks:** WorkManager
- **Backend (optional):** Firebase
- **IDE:** Android Studio

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Kotlin support
- Android device or emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/minahil607/CareNest.git
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync.

4. Run the application on an Android emulator or physical device.

## 🔒 Privacy & Safety

CareNest is intended to help organize caregiving information. Medical information and reminders should be verified by caregivers and healthcare professionals.

The app is not intended to diagnose, treat, or replace professional medical advice.

## 🎯 Project Goal

The goal of CareNest is to build a simple digital companion for family caregivers that helps them stay on top of daily responsibilities, reduce missed reminders, and provide better-organized care for their loved ones.
